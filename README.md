# 🥤 Animation Refri

Projeto de uma página animada de refrigerantes com diferentes sabores, desenvolvido utilizando **HTML, CSS e JavaScript**.

O projeto possui uma interface interativa onde o usuário pode navegar entre os sabores utilizando as setas, alterando o produto exibido na tela.

## 🚀 Funcionalidades

- Navegação entre diferentes sabores
- Botões de próximo e anterior
- Alteração dinâmica dos produtos
- Animações visuais
- Layout moderno e interativo
- Imagens personalizadas para cada sabor

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
